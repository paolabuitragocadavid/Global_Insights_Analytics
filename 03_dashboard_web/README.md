
# Dashboard interactivo — Global Insights Analytics

## Descripción
Panel interactivo desarrollado con Python y Plotly
para analizar oportunidades de mercado digital.

## Acceso al dashboard publicado

[Abrir dashboard interactivo — Global Insights Analytics](https://global-insigths-dash-paola-buitrago.netlify.app/)

## Características
- Cinco indicadores clave (KPI).
- Seis visualizaciones interactivas.
- Filtros por país y periodo.
- Selección del indicador de clasificación.
- Análisis de 13 países entre 2015 y 2023.

## Herramientas
Google Colab, Python, Plotly, HTML y Netlify.
