## Descripción del proyecto

Global Insights Analytics es un proyecto académico de analítica y visualización de datos orientado a comparar mercados digitales mediante indicadores socioeconómicos, demográficos y tecnológicos.

El análisis integra información de 13 países durante el periodo 2015–2023, utilizando fuentes del Banco Mundial, Our World in Data/UIT y documentación de la OCDE.

## Objetivo

Integrar, procesar y visualizar datos heterogéneos para identificar tendencias, asociaciones y perfiles nacionales que permitan orientar investigaciones comerciales y decisiones empresariales basadas en evidencia.

## Herramientas utilizadas

- Google Colab y Python.
- Pandas y NumPy.
- Plotly y Matplotlib.
- Power BI Desktop.
- SQLite y Parquet.
- Netlify para publicación web.

## Indicadores principales

El dashboard presenta cinco indicadores: países analizados, uso medio de Internet, PIB per cápita medio, población total e índice exploratorio de mercado digital.

## Visualizaciones

1. Evolución temporal del uso de Internet.
2. Clasificación interactiva de países.
3. Relación entre PIB per cápita y uso de Internet.
4. Matriz de correlación de Spearman.
5. Distribución del uso de Internet mediante cajas y bigotes.
6. Mapa de calor país–año.

## Alcance y limitaciones

El índice exploratorio permite comparar perfiles nacionales, pero no constituye una predicción de ventas o rentabilidad. Las asociaciones estadísticas no deben interpretarse como relaciones causales.
